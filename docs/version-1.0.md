# 版本 1.0 说明

## 定位

这是第一阶段的最小可运行版，目标不是复刻现有竞品界面，而是验证最核心的客服回复闭环是否可用：

1. 管理短语与分类
2. 选择短语
3. 通过系统剪贴板和按键模拟把内容送到任意聊天窗口

## 本阶段实现

- WPF Windows 桌面应用基础框架
- 分类 CRUD
- 短语 CRUD
- 搜索过滤
- 本地 JSON 持久化
- 最近外部窗口记录
- `Ctrl+V` 粘贴
- 可配置发送按键：
  - `Enter`
  - `Ctrl+Enter`
  - `Alt+S`

## 暂不实现

- 文件/图片发送
- 富文本模板
- 多级分类
- 全局热键
- 托盘常驻
- 云同步

## 验证方式

1. 运行程序
2. 先切到外部聊天窗口一次
3. 回到本工具编辑或选择一条短语
4. 点击 `粘贴到目标窗口`
5. 再测试 `粘贴并发送`

如果目标软件发送键不是默认 `Enter`，可先切换成 `Ctrl+Enter` 或 `Alt+S` 再验证。
