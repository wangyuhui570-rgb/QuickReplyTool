## 本次修复

- 短语导出使用独立配图目录，先完成临时表格再替换目标文件。导出失败保留原表格和配图。
- 图文话术缺少任意配图时，发送、输入、复制和导出会提示补全图片，覆盖主界面、搜索浮层和快捷标签入口。
- XLS、CSV 分别保留标题与检索标签，兼容旧格式，空标签保持为空。
- 发送或文件操作失败、取消时，次数和最近使用时间保持原值。
- 导入涉及多个同名分类时，先选择归属。取消选择时话术和图片均不写入，提交失败时回滚。
- 文件库同步改为批量事务，支持失败重试，并发加入相同路径时复用文件标识。
- 搜索结果批量通知，结果相同时保留列表，搜索和选中项同步刷新。

## 更新和测试

- 2.1.35 绿色版可通过软件内更新获取 2.1.35 → 2.1.36 增量补丁。
- 移动导出的备份时，请同时携带表格和它引用的配图目录。重复导出会保留旧配图目录。
