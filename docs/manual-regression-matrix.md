# QuickReplyTool 手工回归矩阵

## 使用方式

- 候选发布前至少完整执行一次
- 正式发布前对安装包、便携包、正式 OTA 包、补丁包各执行一次相关场景
- 每个场景都要记录执行人、时间、版本号、截图或日志位置

## 包型拆分建议

- 候选发布：执行下面 12 个核心场景的完整矩阵
- 安装包发布：在完整矩阵基础上，额外确认安装、首次启动、重启持久化、卸载或清理路径
- 便携包发布：在完整矩阵基础上，额外确认解压、批处理启动、便携目录结构、二次启动后的设置持久化
- 正式 OTA 发布：在完整矩阵基础上，额外确认检查更新、在线下载、自动重启、更新后用户数据保留
- 补丁包发布：在完整矩阵基础上，额外确认补丁包下载、计划文件、重启生效、状态标记与补丁后冒烟

如果使用 `scripts\new-release-evidence.ps1` 生成证据目录，`packaging-upgrade\` 下会附带：

- `installer-release-checklist.md`
- `portable-release-checklist.md`
- `ota-release-checklist.md`
- `patch-release-checklist.md`

## 核心场景

### 1. 记事本文本输入与发送

- 前置条件：打开记事本并让输入区域处于可编辑状态
- 步骤：从主界面或搜索面板选择一条纯文本短语，分别执行“输入”和“发送”
- 期望：文本内容正确进入目标窗口；发送模式下快捷键行为符合设置
- 留证：记事本截图，发送诊断日志

### 2. 微信或等价 IM 文本发送

- 前置条件：打开实际 IM 聊天窗口并聚焦输入框
- 步骤：执行纯文本短语发送
- 期望：焦点能切回目标窗口，文本完整，未误发到错误窗口
- 留证：聊天窗口截图，异常时保存搜索/发送日志

### 3. 浏览器输入框文本发送

- 前置条件：浏览器打开一个普通文本输入框
- 步骤：执行纯文本短语输入和发送
- 期望：不同宿主控件下仍能稳定 paste
- 留证：浏览器截图

### 4. `Enter / Ctrl+Enter / Alt+S` 三种发送方式

- 前置条件：在设置中分别切换三种发送热键
- 步骤：每种热键至少执行一次文本发送
- 期望：发送动作与当前配置一致，没有串用旧配置
- 留证：设置截图与目标窗口结果截图

### 5. 文本 + 单图发送

- 前置条件：准备一条带图片的短语
- 步骤：执行发送
- 期望：图片和文本顺序符合当前图文发送模式；失败时给出明确提示
- 留证：聊天窗口截图

### 6. 多图或文件发送

- 前置条件：文件库中存在多个文件，或短语关联多张图片
- 步骤：执行输入/发送
- 期望：文件列表完整进入目标窗口，缺失文件要被拦截
- 留证：目标窗口截图，必要时附带日志

### 7. 搜索面板打开、模式切换、推荐点击发送

- 前置条件：存在足够的搜索样本和推荐候选
- 步骤：打开搜索面板，切换模式，点击推荐发送
- 期望：空态、推荐态、模式切换都正常；点击不会误发其他内容
- 留证：操作录屏或连续截图

### 8. 首次启动引导与设置保存

- 前置条件：使用干净数据目录或新环境
- 步骤：启动应用，完成首启引导，修改一组设置并重启
- 期望：引导流程完整，设置能持久化
- 留证：首启截图、重启后截图

### 9. 问题记录生成本地 md/json 并尝试上传

- 前置条件：配置问题上报目录；如有联调环境可配置服务器
- 步骤：提交一条问题描述
- 期望：本地生成 `.md` 与 `.json`；有服务器时能更新状态，无服务器时给出清晰提示
- 留证：生成文件路径、上传结果截图

### 10. 云同步手动触发与更新检查

- 前置条件：配置联调环境地址、客户端标识和访问令牌
- 步骤：手动触发云同步，再触发更新检查
- 期望：增量时间戳更新；失败时能保留可读错误信息
- 留证：设置页截图、服务端响应日志

### 11. zip 补丁自更新

- 前置条件：准备一个可下载的 zip 包，或联调环境提供补丁地址
- 步骤：执行下载并安装补丁，等待应用重启
- 期望：下载目录、计划文件、日志和状态标记正确生成；升级后有状态提示
- 留证：更新日志、升级后截图

### 12. 截图工具自动启动、关闭、设置写入

- 前置条件：本机安装可用的 Python 运行环境及截图工具依赖
- 步骤：开启/关闭“随应用启动截图工具”，修改热键和保存目录
- 期望：配置写入正确，工具状态与主程序设置一致
- 留证：截图工具配置文件、实际运行截图
