# LiteShot 轻截图

当前主版本是托盘常驻模式：

- 启动后不弹主窗口，只显示系统托盘图标
- 默认全局快捷键 `Ctrl+Alt+A`
- 托盘右键可打开“快捷键设置”
- 截图时可自动识别鼠标下的窗口/控件，单击直接确认
- 拖拽框选后直接在截图层原地编辑
- 支持箭头、矩形、圆形、打码、复制、保存、另存为

## 启动

直接双击：

- `launch_screenshot_tool.bat`
- `启动截图工具.bat`

或者手动运行：

```powershell
python lite_shot.py
```

## 说明

- 单击托盘图标可直接截图。
- 右键托盘图标可修改快捷键、默认保存目录或退出。
- 进入截图后，移动鼠标会自动高亮窗口或控件，单击可直接选中。
- 如果不想吸附窗口/控件，按住左键拖动即可手动画框。
- 默认保存目录是桌面，可在设置里修改。
- 矩形和圆形支持基础颜色切换，默认红色。
- 编辑时快捷键：
  - `A` 箭头
  - `R` 矩形
  - `C` 圆形
  - `M` 打码
  - `Ctrl+C` 复制
  - `Ctrl+Z` 撤销
  - `Esc` 取消
